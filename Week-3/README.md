# Week 3 – Python Programming Tasks

This folder contains the Python programming tasks completed during **Week 3** of my internship. The tasks focus on object-oriented programming, calculations, transaction handling, and management system development using Python.

## 🛠️ Technologies Used

* Python 3
* VS Code
* Git & GitHub

## 📂 Tasks Completed

### 1. Bank Account

A Python program that simulates basic bank account operations such as:

* Creating an account
* Depositing money
* Withdrawing money
* Checking account balance

### 2. Billing System

A simple billing application that calculates the total bill based on items, quantities, and prices.

### 3. Calculator

A basic calculator program that performs arithmetic operations such as:

* Addition
* Subtraction
* Multiplication
* Division

### 4. Library Management System

A Python-based library management system for managing books and performing basic library operations such as adding, issuing, returning, and viewing books.
