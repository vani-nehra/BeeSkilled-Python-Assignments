# Week 4 – Python Projects

This folder contains the Python projects completed during **Week 4** of my internship. The tasks focus on APIs, automation, data handling, and building practical Python applications.

## 🛠️ Technologies Used

* Python 3
* REST APIs
* JSON
* CSV
* SMTP / Email Automation
* VS Code
* Git & GitHub

## 📂 Projects Completed

### 1. Live Cryptocurrency Tracker

A Python application that fetches and displays **live cryptocurrency prices** using an external API.

**Key Concepts:**

* API integration
* HTTP requests
* JSON response handling
* Working with real-time data

### 2. Simple Calculator

A basic calculator application that performs common arithmetic operations such as:

* Addition
* Subtraction
* Multiplication
* Division

### 3. Weather App

A Python application that retrieves and displays **weather information** using a weather API.

**Key Concepts:**

* API integration
* User input
* JSON data handling
* Extracting information from API responses

### 4. Contact Book

A Python-based contact management application that allows users to store, view, search, and manage contact information.

### 5. Email Automation Tool

A Python-based automation tool that reads student information from a CSV file and sends **personalized emails automatically**.

**Key Concepts:**

* CSV file handling
* Email automation
* SMTP
* Personalized email generation
* Automation using Python

## 📄 Supporting File

### students.csv

A CSV dataset containing student names and email addresses used by the **Email Automation Tool** for sending personalized emails.

1. Install **Python 3**.
2. Open the Week 4 folder in VS Code.
3. Install the required libraries, if needed.

4. Keep required files such as students.csv in the appropriate project folder.
